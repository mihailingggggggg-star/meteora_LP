# Журнал бота

Здесь живёт вся история решений. Формат рассчитан на то, чтобы **ИИ мог читать, парсить и находить ошибки**.

## Файлы

| Файл | Что внутри | Кто читает |
|---|---|---|
| `YYYY-MM-DD.md` | человекочитаемый поток решений и событий | вы и ИИ (анализ) |
| `YYYY-MM-DD-summary.md` | итог дня: прогноз vs факт, ошибки модели, гипотезы | ИИ (улучшение стратегии) |
| `events.jsonl` | машинный поток, одна JSON-запись на строку | движок, скрипты аналитики |

## Формат строк в `YYYY-MM-DD.md`

```
[HH:MM:SS] ТИП    подробности в одну строку (ключ=значение, ключ=значение)
```

Типы: `BOOT`, `SCAN`, `SCORE`, `REJECT`, `ENTER`, `FILL`, `CLAIM`, `MOVE` (перестановка сеток),
`STOP`, `EXIT_UP`, `EXIT_TIME`, `ERROR`, `WARN`, `HALT` (сработал дневной лимит), `SUMMARY`.

Пример:

```
[14:03:12] SCAN   пулов получено 139352, прошли фильтры 42, кандидатов 5
[14:03:12] SCORE  TOKEN/SOL score=2.31%/15h T_r=$18.4k C=$320 f=1.00% r=0.47 u=0.8 age=31h tvl=$180k vol24=$25k
[14:03:12] REJECT MEME2/SOL R_15h=1.10% < 2.00% (volume 24h -38% за 6ч)
[14:03:13] ENTER  pos#17 C=$320 P_avg=0.003211 P_exit=0.003120 worst=-4.4% ($-14.1) zones=[z1 -2.1%..0%, z2 -6.4%..-2.1%]
[14:05:00] FILL   pos#17 bin=-3 side=sol→token sol=0.42 token=1284.0 price=0.003270
[17:41:09] STOP   pos#17 price=0.003119 ≤ P_exit=0.003120 slippage=0.42% latency=2.1s pnl=-13.9
```

## Правило для ИИ при анализе

1. Читать `events.jsonl` (машинно) → строить агрегаты; `md` — для контекста и формулировок.
2. Для каждой закрытой позиции сравнивать `predicted_r_15h` (на входе) с фактическим `pnl_pct`.
   Систематическое расхождение > 30% → ошибка модели, а не «неудача рынка».
3. Любой `ERROR` подряд ≥ 3 раз — искать причину в коде/лимитах API, а не «ретраить».
4. Гипотезы улучшений писать в `YYYY-MM-DD-summary.md` блоком `## Гипотезы`, а не менять логику молча.
